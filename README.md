# Elpino

**An AI support agent that learns your website and runs customer support on autopilot.**

[Try the live demo](https://elpino.chat/demo) · [Website](https://elpino.chat) · [Docs](https://elpino.chat/docs)

## Our repositories

| Repository | What it is | License |
| --- | --- | --- |
| [elpino_web](https://github.com/elpino-chat/elpino_web) | The website, dashboard and embeddable chat widget (Next.js, TypeScript) | MIT |
| [wordpress-plugin](https://github.com/elpino-chat/wordpress-plugin) | Add the Elpino chat widget to a WordPress site | GPL-2.0-or-later |

The AI agent and the backend services are not open source.

## About this repository

This repository holds Elpino's organization profile and the default community files shared by all of our
repositories: the [Code of Conduct](CODE_OF_CONDUCT.md), [Contributing guide](CONTRIBUTING.md),
[Security policy](SECURITY.md), and the issue and pull request templates. A repository can override any of them by
adding its own copy.

To report a security problem, email **security@elpino.chat**. Please do not open a public issue.
