Paste your site and Elpino reads your public pages, answers your customers from them, and hands the conversation to your team when it isn't sure.

## Open source

| Repository | What it is | License |
| --- | --- | --- |
| 🌐 [elpino_web](https://github.com/elpino-chat/elpino_web) | The website, dashboard and embeddable chat widget (Next.js, TypeScript) | MIT |
| 🔌 [wordpress-plugin](https://github.com/elpino-chat/wordpress-plugin) | Add the Elpino chat widget to a WordPress site | GPL-2.0-or-later |

The AI agent and the backend services are not open source.

## Get involved

- Found a bug or have an idea? Open an issue in the relevant repository.
- Want to contribute? Read [CONTRIBUTING.md](CONTRIBUTING.md) first. Pull requests are welcome.
- Security problem? Email **security@elpino.chat** and please do not open a public issue. See [SECURITY.md](SECURITY.md).
